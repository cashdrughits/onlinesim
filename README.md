# Шаблоны ответов — onlinesim.io / onlineproxy.io

Личный сайт с шаблонами ответов поддержки. Чистый HTML/CSS/JS, без сборки — публикуется напрямую через GitHub Pages.

## Как опубликовать на GitHub Pages

1. Создай новый репозиторий на GitHub (например `support-templates`).
2. Залей в него все файлы из этой папки (`index.html`, `styles.css`, `app.js`, `templates.js`).
3. В репозитории: **Settings → Pages → Source** выбери ветку `main` и папку `/ (root)`.
4. Через минуту сайт будет доступен по адресу вида `https://<твой-юзернейм>.github.io/support-templates/`.

Если хочешь, чтобы репозиторий был приватным, но сайт всё равно работал — GitHub Pages для приватных репо доступен только на платных планах (Pro и выше). Иначе сделай репозиторий публичным — ссылку на сайт никто не узнает, если её не публиковать.

## Как редактировать шаблоны

Все шаблоны лежат в одном файле — **`templates.js`**. Каждый шаблон — это объект:

```js
{
  id: "svc-wa-1",                 // уникальный id, латиницей
  category: "services",           // id категории из CATEGORIES
  title: "Короткое название",     // заголовок карточки
  ru: `Текст на русском`,
  en: `Text in English`,
  tags: ["ключевые", "слова", "для поиска"],
  hasServicePlaceholder: true,    // опционально: если в тексте есть {{service}}
}
```

Чтобы добавить новый шаблон — скопируй любой существующий объект внутри массива `TEMPLATES`, измени поля и сохрани файл.

Чтобы добавить новую категорию — допиши её в массив `CATEGORIES` в начале файла:

```js
{ id: "my-category", name: "Моя категория", icon: "tag" }
```

### Плейсхолдер `{{service}}`

Если в тексте шаблона есть `{{service}}`, сайт автоматически покажет под заголовком карточки поле ввода. Всё, что туда впишешь, подставится вместо `{{service}}` в обеих версиях (RU и EN) перед копированием.

## Возможности сайта

- 🔍 Поиск по ключевым словам сразу по всем шаблонам (заголовок, текст RU/EN, теги) — не привязан к категориям.
- 🗂 Фильтр по категориям (пилюли сверху).
- 🌗 Переключение светлая/тёмная тема (запоминается в браузере).
- 🇷🇺🇬🇧 Переключение RU/EN прямо в карточке.
- 📋 Копирование одним кликом с визуальным подтверждением.
- ✏️ Поле быстрой подстановки названия сервиса для универсальных шаблонов.

## Структура файлов

```
index.html     — разметка страницы
styles.css     — все стили, включая тёмную тему
app.js         — логика (поиск, фильтры, рендер, копирование)
templates.js   — ДАННЫЕ: все шаблоны и категории (редактируй этот файл)
```
